אבני הבניין של ה-AI

הבסיס התיאורטי שעליו מושתתת כל מערכת חכמה בעולם החדש.

נתונים (Data)

חומר הגלם של הבינה המלאכותית. המידע שמזין את המערכות ומאפשר להן ללמוד דפוסים, לזהות מגמות ולקבל החלטות מבוססות מציאות.

מודל (Model)

ייצוג מפושט של מערכת מורכבת. המודל מתמצת את החוקיות שנלמדה מהנתונים לכדי מנגנון שמסוגל לבצע חיזויים או סיווגים.

אבסטרקציה (Abstraction)

הפחתת רעשים כדי לשמור רק על המאפיינים הקריטיים. זהו למעשה פישוט נתונים לטובת מטרה מסוימת, המאפשר למערכת להתמקד בעיקר.

יועץ המיזמים החכם

פרויקט הדגל שלנו בפייתון המחובר ל-Gemini API. התוכנית מקבלת כקלט "צורך קהילתי", ונעזרת בבינה מלאכותית יוצרת כדי להפיק:

3 פתרונות פרקטיים
שאלה אתית קריטית אחת

זהו שלב ה-Tinkering (ניסוי וטעייה) שבו התלמידים הופכים מצרכנים למפתחים, ומתנסים בקוד חי עם מודלי שפה.

מדריך מעשי: בניית חוקר משפיעים

מדריך זה יוביל אתכם צעד אחר צעד בפיתוח פרויקט הדגל שלכם בפייתון. נחבר את סביבת הפיתוח שלנו למוח של Gemini, וניצור כלי חכם שחוקר דמויות מפתח טכנולוגיות כדי להבין את השרשרת הקריטית: בעיה אנושית ⬅️ טכנולוגיה ⬅️ השפעה חיובית.

1

יצירת מפתח מפתחים (API Key)

כדי שהקוד שלנו יוכל "לדבר" עם הבינה המלאכותית של גוגל, אנחנו צריכים תעודת זהות ייחודית שנקראת API Key.

  1. היכנסו לאתר Google AI Studio.
  2. התחברו עם חשבון ה-Google שלכם.
  3. בתפריט הצדדי (או במסך הראשי), חפשו ולחצו על הכפתור Get API key.
  4. לחצו על הכפתור הכחול Create API key.
  5. בחרו באפשרות של יצירת מפתח בפרויקט חדש (Create API key in new project).
  6. לאחר מספר שניות יופיע על המסך רצף של אותיות ומספרים. העתיקו אותו ושמרו אותו במקום בטוח (אל תשתפו אותו עם אף אחד!).
2

הגדרת סביבת העבודה ב-Google Colab

Colab היא מחברת דיגיטלית שמאפשרת לנו לכתוב ולהריץ קוד פייתון ישירות בדפדפן.

  1. היכנסו ל-Google Colab.
  2. לחצו על New Notebook (מחברת חדשה).
  3. בתא הקוד הראשון שמופיע (התא האפור), עלינו להתקין את הספרייה של Google Generative AI. העתיקו את השורה הבאה לתא, ולחצו על כפתור ה-Play (משולש קטן בצד) כדי להריץ:
bash 
!pip install -U google-generativeai

המתינו מספר שניות עד שתראו שההתקנה הסתיימה בהצלחה (יופיע V ירוק או הודעת Success).

3

כתיבת הקוד והפרומפט (הלב של הפרויקט)

כעת, פתחו תא קוד חדש (לחצו על + Code). העתיקו אליו את הקוד הבא.
חשוב: אל תשכחו להדביק את מפתח ה-API שלכם היכן שכתוב הכנס_את_המפתח_שלך_כאן.

כתיבת פרומפט מנצח - מודל המתופ"ף

כדי לקבל את התשובה הטובה ביותר מהבינה המלאכותית, נשתמש במודל המתופ"ף לבניית הפרומפט שמופיע בקוד:

  • מ - מומחה: הגדרת התפקיד של ה-AI ("אתה יועץ מיזמים ומומחה...").
  • ת - תיאור המשימה: מה אנחנו רוצים שהמודל יעשה ("אנא חקור את המשפיען...").
  • ו - והקשר (קונטקסט): רקע לבעיה ולמידע ("אני תלמיד במגמת מדעני בינה מלאכותית...").
  • פ - פורמט: איך להציג את התשובה ("בצורה ברורה, מעוררת השראה, השתמש בכותרות...").
  • ף - פרטים מדויקים: המבנה הספציפי הנדרש (תעודת זהות, הבעיה, הטכנולוגיה, ההשפעה, המצפן האתי).
python 
import google.generativeai as genai

# 1. חיבור המפתח שלכם (API Key)
# החליפו את הטקסט בין המרכאות במפתח שהעתקתם בשלב 1
GOOGLE_API_KEY = "הכנס_את_המפתח_שלך_כאן"
genai.configure(api_key=GOOGLE_API_KEY)

# 2. הגדרת המודל שבו נשתמש
model = genai.GenerativeModel('gemini-2.5-flash')

# 3. קליטת נתונים מהמשתמש (אינטראקציה)
print("=== ברוכים הבאים ליועץ המיזמים החכם ===")
print("כאן הופכים קוד להשפעה חברתית.")
influencer_name = input("איזו דמות תרצו לחקור? (לדוגמה: ד''ר קירה רדינסקי, ג'וי בולמוויני, סאל חאן): ")

# 4. הפרומפט המדויק למודל
# כאן אנחנו מגדירים ל-AI בדיוק איזה תפקיד לשחק ואיך לנתח את המידע
prompt = f"""
אתה יועץ מיזמים ומומחה להיסטוריה של הבינה המלאכותית.
אני תלמיד במגמת "מדעני בינה מלאכותית". המטרה שלי היא לחקור כיצד אנשים זיהו בעיה, בחרו בטכנולוגיה הנכונה, והשפיעו על העולם לטובה.

אנא חקור את המשפיען/ית: {influencer_name}.

הצג את המידע בצורה ברורה, מעוררת השראה, ובשפה מותאמת לתלמידי חטיבת ביניים, בדיוק לפי המבנה הבא (השתמש בכותרות):

1. **תעודת זהות**: שם מלא, תחום פעילות מרכזי, ומשפט אחד המסכם את החזון של הדמות.
2. **הבעיה האנושית**: שאלות טכנולוגיות טובות מתחילות בשאלה אנושית. איזו בעיה או מצוקה הדמות הזו זיהתה לפני שהיא התחילה לפתח פתרון? מי האנשים שסבלו מהבעיה הזו?
3. **הטכנולוגיה והפתרון**: באיזו טכנולוגיה (למשל: סיווג תמונות, ניתוח נתונים רפואיים, מודלי שפה, אלגוריתמים לזיהוי פנים) הדמות השתמשה כדי לפתור את הבעיה? כיצד הטכנולוגיה עובדת ברמת העיקרון?
4. **ההשפעה על העולם (Impact)**: כיצד הפתרון הזה הפך קוד להשפעה חברתית? איך הוא עזר לאנשים בפועל?
5. **המצפן האתי**: טכנולוגיה היא כוח, ועם כוח מגיעה אחריות. נסח שאלה אתית קריטית אחת שעולה מהשימוש בטכנולוגיה של דמות זו (למשל: חשש להטיות בנתונים, פגיעה בפרטיות, או האם זה יחליף בני אדם).
"""

# 5. שליחת הפרומפט והצגת התשובה
print("\nיועץ המיזמים חוקר את הרשת ומנתח את הנתונים... אנא המתן...\n")

try:
    response = model.generate_content(prompt)
    print(response.text)
except Exception as e:
    print(f"אופס, נתקלנו בתקלה (באג). בדקו שהמפתח שלכם תקין. פרטי השגיאה: {e}")
4

מריצים ומתנסים (Tinkering)

  1. לאחר שהדבקתם את המפתח שלכם והעתקתם את הקוד, לחצו על כפתור ה-Play של התא.
  2. בתחתית התא תופיע שורת קלט (Input).
  3. הקלידו שם של משפיע/ה מתוך נבחרת המשפיעים שלמדנו עליהם (למשל: Joy Buolamwini או קירה רדינסקי) ולחצו Enter.
  4. צפו ביועץ המיזמים שלכם מייצר עבורכם דוח מחקר מפורט!
אתגר למתקדמים:

נסו לשנות את משתנה ה-prompt שבקוד. הוסיפו לו בקשה נוספת, למשל:
"בסוף הדו"ח, הצע לי רעיון לפרויקט קטן ב-Teachable Machine שאני יכול לבנות בהשראת הדמות הזו".
הריצו שוב ובדקו כיצד התשובה משתנה.

אם לא עובד: בדיקת מודלי טקסט נתמכים

לפעמים גוגל מעדכנת את שמות המודלים. אם אתם מקבלים שגיאה, הריצו את הקוד הבא בתא חדש ב-Colab כדי לראות אילו מודלים זמינים לכם כעת ותומכים ביצירת טקסט:

python 
!pip install -U google-generativeai

import google.generativeai as genai

def check_supported_models():
    """Lists supported models and checks if they can run prompts."""
    print("Available models that support text generation:\n")
    for m in genai.list_models():
        if "generateContent" in m.supported_generation_methods:
            print(f"  Model name: {m.name}")
            print(f"  Description: {m.description}")
            print(f"  Supported methods: {m.supported_generation_methods}\n")

check_supported_models()

מטלה: שלב התכנות - בניית "יועץ המיזמים"

במטלה זו, התלמידים יכתבו קוד המיישם את המבנה הבא כדי לבנות את הכלים שחוקרים פתרונות ואתיקה:

  • קבלת הקלט:
    המשתמש מזין את הצורך הקהילתי שאותו הוא מעוניין לפתור.
  • בניית הפרומפט המורכב:
    התלמידים ינחו את Gemini להציע פתרונות מעשיים לאותו צורך, ובנוסף, יבקשו ממנו לשאול שאלות אתיות שעולות מהפתרונות המוצעים.
יועץ המיזמים - הצעה לפרומפט

תפקיד: פעל כמומחה ליזמות חברתית, פיתוח קהילתי ואתיקה יישומית.

הקשר: אני מעוניין למצוא מענה לצורך קהילתי ספציפי שאיתרתי:
[כאן יש להגדיר בקצרה את הצורך. דוגמה: בדידות בקרב קשישים בשכונה / חוסר נגישות למזון בריא / שילוב נוער בסיכון בפעילויות ספורט].

המשימה שלך מורכבת משני חלקים:

  • פתרונות מעשיים: הצע 3 פתרונות פרקטיים, יצירתיים ובר-קיימא (ניתנים ליישום) כדי לתת מענה לצורך זה. עבור כל פתרון, תאר בקצרה איך הוא עובד ומהם הצעדים הראשונים ליישומו.
  • שאלות אתיות: נתח את הפתרונות שהצעת והעלה 3 שאלות אתיות מורכבות שעשויות לעלות מתוכם (לדוגמה: סוגיות של פרטיות, פגיעה באוטונומיה, יצירת תלות, הוגנות בחלוקת משאבים, או הדרה לא מכוונת של תתי-קבוצות בקהילה). הסבר בקצרה מדוע חשוב לתת עליהן את הדעת.
